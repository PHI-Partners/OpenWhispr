# Backlog 1.1.2 — Secure Window Bootstrap and Typed IPC Bridge Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The renderer calls a typed `window.api` exposed by a sandboxed, bundled preload, and TypeScript fails whenever the preload, the `Api` interface and the channel contract drift apart.

**Architecture:** `src/shared/ipc.ts` is the single source of the contract: channel constants split into invoke (renderer → main) and event (main → renderer) channels, one signature/payload map per kind keyed by those constants, and `Api` derived from the maps so every method names its channel. The preload implements `Api` through two typed helpers (`invoke`, `subscribe`) and exposes it with `contextBridge`; the main window runs sandboxed with context isolation; `registerIpcHandlers(deps)` is wired into startup as the one registration point (empty until feature tasks add handlers).

**Tech Stack:** Electron 44.4.1, electron-vite 5.0.0 (Vite 7.3.6), TypeScript 6.0.3 (`tsc -b`, node + web projects), React 19, playwright-cli 0.1.20 for app-level checks.

**Spec:** `docs/BACKLOG.md` task 1.1.2 and its "Architecture reference"; `docs/ARCHITECTURE.md` §1.

## Global Constraints

- Channels are kebab-case; the five v1 methods keep their exact names and channels: `startMeetingRecording` → `meeting-recording-start`, `stopMeetingRecording` → `meeting-recording-stop`, `onTranscriptUpdate` → `transcript-update`, `listMeetings` → `db-list-meetings`, `getMeeting` → `db-get-meeting`.
- `window.api` via `contextBridge`; every `on*` subscription returns an unsubscribe function.
- Every `ipcMain.handle` is registered centrally in `src/main/ipc/ipcHandlers.ts` with injected services.
- Main window: `contextIsolation: true`, `sandbox: true`, `nodeIntegration: false`, `backgroundThrottling: false`, no experimental web features.
- No new dependencies; toolchain pins stay as they are (see memory "toolchain-pin-constraints").
- `erasableSyntaxOnly` is on (no `enum`/`namespace`); `verbatimModuleSyntax` is on (`type` modifier on type-only imports).
- The Epic 2 test harness does not exist yet: compile-time checks run through `npx tsc -b`, app-level checks through playwright-cli over CDP (CLAUDE.md), main-process checks through the V8 inspector.
- No commits unless the user asks.

## Research findings the tasks rely on

- Sandboxed preloads cannot use ESM and their `require` only knows `electron`, `events`, `timers`, `url` — local chunks and npm packages must be bundled (Electron sandbox + ESM docs). electron-vite 5 always externalizes `electron` and Node built-ins for the preload, emits CJS (`package.json` has no `"type": "module"`), and externalizes `dependencies` unless `build.externalizeDeps: false`, which its docs call required for sandboxed preloads.
- `ipcRenderer.on` listeners must not receive the `IpcRendererEvent`: `event.sender` is `ipcRenderer` (Electron security guide).
- `skipLibCheck: true` skips *all* `.d.ts` files: a global typing in `env.d.ts` whose import breaks silently becomes `any` (reproduced in a scratch project), so the renderer typing lives in a `.ts` file.
- Scratch-compiled against Electron 44 typings, the design below rejects: a missing preload method (TS2741), a method wired to a channel with another result (TS2322), an extra method (TS2353), a dropped argument (TS2554), and a channel constant without a contract entry (TS2536 in `ipc.ts`).

```ts
import { contextBridge, ipcRenderer, type IpcRendererEvent } from 'electron';
import { type Api, EventChannel, type EventContract, InvokeChannel, type InvokeContract } from '@shared/ipc';

function invoke<C extends InvokeChannel>(
  channel: C,
  ...args: Parameters<InvokeContract[C]>
): Promise<ReturnType<InvokeContract[C]>> {
  return ipcRenderer.invoke(channel, ...args);
}

function subscribe<C extends EventChannel>(
  channel: C,
  listener: (payload: EventContract[C]) => void,
): () => void {
  // Only the payload crosses over: the event would hand the page `event.sender`, i.e. ipcRenderer.
  const forward = (_event: IpcRendererEvent, payload: EventContract[C]): void => listener(payload);
  ipcRenderer.on(channel, forward);
  return () => {
    ipcRenderer.removeListener(channel, forward);
  };
}

const api: Api = {
  startMeetingRecording: () => invoke(InvokeChannel.MeetingRecordingStart),
  stopMeetingRecording: () => invoke(InvokeChannel.MeetingRecordingStop),
  onTranscriptUpdate: (listener) => subscribe(EventChannel.TranscriptUpdate, listener),
  listMeetings: () => invoke(InvokeChannel.DbListMeetings),
  getMeeting: (id) => invoke(InvokeChannel.DbGetMeeting, id),
};

contextBridge.exposeInMainWorld('api', api);
```

- [ ] **Step 3: Write the contract**

`src/shared/ipc.ts`:

```ts
/** Request/response channels: renderer `ipcRenderer.invoke` → main `ipcMain.handle`. */
export const InvokeChannel = {
  MeetingRecordingStart: 'meeting-recording-start',
  MeetingRecordingStop: 'meeting-recording-stop',
  DbListMeetings: 'db-list-meetings',
  DbGetMeeting: 'db-get-meeting',
} as const;
export type InvokeChannel = (typeof InvokeChannel)[keyof typeof InvokeChannel];

/** Push channels: main `webContents.send` → renderer `ipcRenderer.on`. */
export const EventChannel = {
  TranscriptUpdate: 'transcript-update',
} as const;
export type EventChannel = (typeof EventChannel)[keyof typeof EventChannel];

export interface StartMeetingRecordingResult {
  sessionId: string;
  captureSystemAudio: boolean;
}

export interface TranscriptUpdate {
  sessionId: string;
  seq: number;
  text: string;
  startSec: number;
  endSec: number;
}

/** A row of the `meetings` table (ARCHITECTURE §4). */
export interface Meeting {
  id: number;
  title: string;
  transcript: string;
  audioPath: string | null;
  durationSeconds: number | null;
  createdAt: string;
}

export interface MeetingSummary extends Pick<Meeting, 'id' | 'title' | 'createdAt' | 'durationSeconds'> {
  transcriptPreview: string;
}

/** Handler signature per invoke channel; a channel without an entry breaks `InvokeMethod`. */
export interface InvokeContract {
  [InvokeChannel.MeetingRecordingStart]: () => StartMeetingRecordingResult;
  [InvokeChannel.MeetingRecordingStop]: () => void;
  [InvokeChannel.DbListMeetings]: () => MeetingSummary[];
  [InvokeChannel.DbGetMeeting]: (id: number) => Meeting;
}

/** Payload per event channel; a channel without an entry breaks `SubscribeMethod`. */
export interface EventContract {
  [EventChannel.TranscriptUpdate]: TranscriptUpdate;
}

export type InvokeMethod<C extends InvokeChannel> = (
  ...args: Parameters<InvokeContract[C]>
) => Promise<ReturnType<InvokeContract[C]>>;

/** Registers the listener and returns the function that removes it. */
export type SubscribeMethod<C extends EventChannel> = (
  listener: (payload: EventContract[C]) => void,
) => () => void;

/** `window.api`: each method is bound to the channel named in its type. */
export interface Api {
  startMeetingRecording: InvokeMethod<typeof InvokeChannel.MeetingRecordingStart>;
  stopMeetingRecording: InvokeMethod<typeof InvokeChannel.MeetingRecordingStop>;
  onTranscriptUpdate: SubscribeMethod<typeof EventChannel.TranscriptUpdate>;
  listMeetings: InvokeMethod<typeof InvokeChannel.DbListMeetings>;
  getMeeting: InvokeMethod<typeof InvokeChannel.DbGetMeeting>;
}
```

`src/main/index.ts`:

```ts
import { join } from 'node:path';
import { app, BrowserWindow } from 'electron';
import { registerIpcHandlers } from './ipc/ipcHandlers';

async function createMainWindow(): Promise<void> {
  const mainWindow = new BrowserWindow({
    webPreferences: {
      preload: join(__dirname, '../preload/index.js'),
      contextIsolation: true,
      sandbox: true,
      nodeIntegration: false,
      // The main window hosts audio capture, which must not be throttled while hidden.
      backgroundThrottling: false,
      experimentalFeatures: false,
    },
  });

  const rendererUrl = process.env.ELECTRON_RENDERER_URL;
  if (!app.isPackaged && rendererUrl) {
    await mainWindow.loadURL(rendererUrl);
  } else {
    await mainWindow.loadFile(join(__dirname, '../renderer/index.html'));
  }
}

app
  .whenReady()
  .then(async () => {
    registerIpcHandlers({});
    await createMainWindow();
  })
  .catch((error: unknown) => console.error('Failed to start the app', error));
```
